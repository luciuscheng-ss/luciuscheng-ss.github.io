iPhone 定位控制台

Windows 桌面小工具：用数据线连上 iPhone 后，在地图上点一下就能把手机定位 瞬间挪过去，或者用鼠标拖画一条自定义路线、设定速度，让手机按这条路径平滑 "移动"。基于开源项目 pymobiledevice3 实现，走的是苹果自己给开发者调试用的定位模拟协议，不需要越狱。

使用前提：Windows 电脑 + iPhone 数据线；iPhone 建议开启 「设置 → 隐私与安全性 → 开发者模式」；首次连接需在手机上点"信任此电脑"。

安卓无线投屏助手

一键把安卓手机切到无线 ADB 并启动 scrcpy 投屏，不用背命令、不用开终端。内置了 adb 和 scrcpy，双击就能用，不需要 额外安装任何东西。

使用前提：手机先用数据线连上电脑、开启「USB 调试」，并连上 和电脑同一个 WiFi；点一下「连接并投屏」，之后就能拔掉数据线了。

Word 文档格式化助手

两个功能：① 复制内置的提示词模板发给豆包（或其他 AI），把它的回复整段 粘贴回来，直接生成排好版的 Word 文档——AI 负责想内容，这个工具负责把 内容和格式正确地做成一个真正的 .docx 文件。 ② 给已有 Word 文档描述一句格式要求（字体/字号/颜色/行距/页边距/页码等）， 自动应用，规则式关键词匹配，不用 API Key。

使用前提：无，打开网页直接用，不用下载安装，文件全程只在 你自己电脑本地处理，不会上传到任何服务器。第一个功能需要你自己已经装了 豆包（或其他能聊天的 AI App/网页）。
